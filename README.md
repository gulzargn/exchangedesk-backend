# ExchangeDesk 🏍️💨
### All-In-One Real-Time Mobile SuperApp (Buyer + Showroom Seller + Super Admin)
**10-Minute Rapid Used Two-Wheeler Exchange Bidding Engine for Showroom Sub-Dealers**

ExchangeDesk is a production-grade, real-time B2B FinTech & AutoTech platform designed for two-wheeler showroom counters (Honda, Hero, TVS, Bajaj, Yamaha, Royal Enfield). 

It bundles **Buyer Live Bidding**, **Showroom Seller Exchange Desk**, and a **Super Admin Control Center** into a single, unified mobile application.

## 🛡️ Critical Anti-Bypass & Security Rules

| Rule | Mechanism | Enforcement |
|---|---|---|
| **1. Strict Data Masking** | Buyers never see customer names, phone numbers, or addresses. Registration numbers are strictly masked (e.g., `MH-04-**-8921`). Showroom counters retain the unmasked RC for paperwork. | Enforced in SQL sanitization transforms and API view filters (`src/utils/masking.js`). |
| **2. Anti-Bypass Protocol** | Winning buyers pay the showroom counter directly to fund the walk-in customer's down payment. The vehicle is released physically only upon presenting a confidential **6-digit Pickup OTP** generated by the showroom desk. | Eliminates off-platform collusion. The handover is authentic and locked until counter settlement. |
| **3. Pre-Funded Wallet Rule** | Used-bike buyers must have at least **₹3,000** in their platform wallet to place live bids. Any bid attempt below ₹3,000 is rejected atomically before database locks are acquired. | Protects showrooms from non-serious, speculative, or bad-faith bidding. |
| **4. Handover Auto-Monetization** | Upon successful verification of the 6-digit Pickup OTP at the showroom counter, the platform automatically deducts a flat **₹500 platform fee** from the winning buyer's wallet in an atomic ACID transaction. | Instant monetization with complete ledger audit trail (`platform_transactions`). |

## 🛠️ Super Admin Control Center Features

1. **Platform Analytics & KPIs**:
   - Total Platform Fee Revenue (sum of ₹500 fees from `platform_transactions`)
   - Total GMV (Value of completed exchange two-wheelers transacted)
   - Active Live Flash Auctions count
   - System Liquidity (Total ₹ deposits in buyer wallets)
2. **Fee Deduction Ledger**:
   - Time-stamped records of all ₹500 deductions with Transaction ID, Vehicle Model, RC Number, Winning Buyer, and Showroom Branch.
3. **Buyer KYC & Liquidity Management**:
   - View all registered buyers, toggle verification status (`VERIFIED` / `UNVERIFIED`).
   - Direct admin wallet credit adjustment (`+₹2,000`, `+₹5,000`).
4. **Showroom Branches Management**:
   - List all branch counters and their total listings.
   - Register new showroom branches directly from the admin console.
5. **Dynamic Rule Configuration**:
   - Live tune platform thresholds without server restarts:
     * Minimum Wallet Balance to Bid (default ₹3,000)
     * Handover Platform Fee (default ₹500)
     * Minimum Bid Increment (default ₹500)
     * Flash Auction Duration (default 10 minutes)

## 🚀 Setup & Execution Guide

### Prerequisites
- Node.js (v18.0.0 or higher recommended, tested on v24.12.0)
- Optional: PostgreSQL (v14 or higher) or Docker

### Step 1: Install Dependencies
```bash
cd C:\Users\ansar\.gemini\antigravity\scratch\exchangedesk
npm install
```

### Step 2: Start the Server
```bash
npm start
```
The server will boot on `http://localhost:3000`.

> **Dual Database Mode**: ExchangeDesk connects to external PostgreSQL when `DATABASE_URL` is set. If no external database is detected, it automatically initializes an embedded in-memory PostgreSQL engine (`pg-mem`) with full ACID and row-locking support.

## 📡 API Reference

### Auctions (`/api/auctions`)
- `POST /api/auctions/create` — Initiates 10-minute flash auction with server-authoritative `ends_at` and 6-digit OTP.
- `GET /api/auctions/active?view=[buyer|showroom]&showroom_id=X` — Returns active auctions with role-based data masking.
- `GET /api/auctions/:id` — Detailed view with full bid history log.
- `POST /api/auctions/verify-handover` — Authenticates 6-digit OTP, deducts ₹500 fee, releases vehicle.

### Super Admin (`/api/admin`)
- `GET /api/admin/stats` — High-level platform KPIs (Revenue, GMV, Liquidity, Active Auctions).
- `GET /api/admin/transactions` — Full fee deduction ledger records.
- `GET /api/admin/buyers` — Detailed buyer KYC and wallet list.
- `POST /api/admin/buyers/:id/toggle-verify` — Toggles buyer verification status.
- `POST /api/admin/buyers/:id/adjust-wallet` — Admin manual wallet credit/debit.
- `POST /api/admin/showrooms/create` — Registers a new showroom branch.
- `POST /api/admin/auctions/:id/cancel` — Emergency admin auction cancellation.
- `POST /api/admin/config` — Updates platform business rules dynamically.
